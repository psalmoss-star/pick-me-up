> ⚠️ **`2026-09-24-fun-plan-v2.md`로 대체됨.** 이 문서는 "정이 들 조건"만 다뤘고, 플레이테스트에서
> "기존 게임과 다르지 않다"는 결과가 나왔다. v2가 순환(전술·정보·육성·장비)을 먼저 세우고
> 이 문서의 평판·거부·첫 5분을 그 위에 얹는다. 이력용으로 남긴다.

> 사용자 질문: "객관적으로, 다른 유저들이 재미있을 것 같나? 원작이 인기를 끌듯 처음 보는 사람도
> 재미있게 — 참신하지만 재미있는 요소로 계획을 세워 달라."
> 아래 판단은 **유저 테스트가 아니라 설계 관점의 추정**이다. 4단계에서 실제로 확인한다.

## 1. 판단 — 지금 상태로는 대부분 재미를 못 느낀다

| 문제 | 근거 |
|---|---|
| 첫 5분에 아무것도 없다 | 첫 화면이 버튼 15개짜리 마을. 설정·목표·걸린 것을 말해주는 장면이 없다 |
| 첫 소환의 설렘이 없다 | `initialRoster()`에 ★5 Lv.40이 이미 있다 |
| 할 일이 얇다 | 전투는 관전 + 개입 3종. 파티 시너지가 없다고 `formation.ts`에 명시돼 있다 |
| 이야기가 생기지 않는다 | 죽으면 무덤에 한 줄. 남에게 말할 사건이 만들어지지 않는다 |

STEP 55(기질·대사)·57(전설)은 "정이 들 조건"이지 정이 드는 **사건**은 아니다.
좋은 것: 이름 봉인·무덤(다른 가챠에 없음), 결정적 전투 재현. **기반이 아니라 방향이 문제다.**

## 2. 원작이 인기를 끈 핵심

가챠·100층이 아니라 **시점의 뒤집힘** — 영웅은 진짜 사람이고, 마스터를 올려다보며 **판단한다.**
지금 게임은 영웅이 말은 하지만 마스터를 판단하지 않고, 마스터의 행동이 영웅에게 아무 영향이 없다.

## 3. 핵심 제안 — "영웅이 마스터를 고른다"

제목 '픽 미 업'을 뒤집는다. **소환에 평판이 생긴다.**

- 마스터 평판 = 무덤 데이터에서 **파생**(저장 안 함): 사망 수, 제물 수, 후퇴 사용, 정상 도달. 회차를 넘어 쌓인다.
- 소환 시 영웅이 기질과 평판으로 **응답/거부**. 거부하면 사유 한 줄을 남기고 사라진다(뽑기 실패가 아니라 사건).
  - 제물이 많은 마스터: 다정은 거부, 냉소·호전은 "너 같은 놈이 편하다"며 응답
  - 아무도 잃지 않은 마스터: 소심이 처음으로 응답
- 전설마다 응답 조건: 아델하르트(오만)는 제물 3명 이상이면 거부, 모르가는 사망자가 많을수록 먼저 온다.
- **전투 수치는 건드리지 않는다** — 뽑히는 사람의 종류만 바뀐다. 결정성: 판정은 개체 시드의 새 스트림.
- ⚠️ 설계 쟁점: 거부 시 재화를 돌려주나? → 초안: 돌려주지 않는다(퍼머데스 원칙과 결이 같음). 사용자 결정 필요.

## 4. 계획

| 단계 | 내용 | 이유 |
|---|---|---|
| 0. 첫 5분 | 오프닝 3장(설정 한 줄). 시작 로스터 ★1~3 네 명, 첫 젬 소환 유도. **전임 마스터의 무덤을 물려받고 시작**(유언이 이미 적혀 있다) | 첫인상. 물려받은 무덤은 기존 시스템에 데이터만 넣으면 된다 |
| 1. 영웅이 마스터를 고른다 | 평판 파생 → 응답/거부 → 거부 사유 대사 → 전설별 조건 | 게임의 정체성 |
| 2. 흉터와 칭호 | 영웅별 이력(참전·후퇴·목격한 죽음) → "7층의 생환자" 같은 칭호. ★1 생존자의 약자 서사 | 남에게 말할 사건 |
| 3. 등반 기록 카드 | 런 종료 시 한 장 이미지로 내보내기(브라우저 안에서만, 외부 통신 없음) | 입소문 |
| 4. 5명 테스트 | 15분씩, 질문 셋: 뭘 하는 게임? 기억나는 순간? 다시 켤까? | 추정을 사실로 바꾼다 |

권장: 0 → 1 → 4(테스트) → 결과 보고 2·3 조정.

⚠️ 0단계의 시작 로스터 변경은 `initialRoster()`를 바꾼다 — `scripts/seed-search.mts`로 다시 재야 한다(CLAUDE.md).
